# Макет нового оформления

Статичный прототип интерфейса журнала. Это **только дизайн** — приложение из корня
репозитория он не трогает и не запускает: цифры зашиты в `data.js` (выгрузка из
демо-данных), сервер не нужен.

Открыть: двойным кликом по `index.html` (он ведёт на `dash.html`).

## Файлы

| Файл | Что внутри |
|---|---|
| `dash.html` | Обзор: неделя, итог месяца с показателями, эквити, колонка-компаньон справа |
| `journal.html` | Журнал: календарь месяца, разбор дня, показатели месяца и года |
| `data.js` | Подготовленные цифры (год, месяц, дни, сделки, сессии, инструменты, сетапы) |
| `common.js` | Расчёты и общие куски разметки — метрики, эквити, календарь |
| `index.html` | Переход на `dash.html` |

## Что решено в макете

- Тёмная графитовая база с мягким белым свечением за интерфейсом: карточки
  полупрозрачные, светлее сверху, поэтому свет проходит сквозь них.
- Цвет только у результата сделки: приглушённые зелёный / розовый / песочный
  для прибыли, убытка и безубытка. Всё остальное — оттенки серого.
- Двойной бордюр у блоков: внешняя оболочка и внутреннее ядро.
- Одна раскладка — основной поток слева, колонка-компаньон справа
  (сессии, инструменты, сетапы за год).
- Последняя неделя вынесена наверх крупным рядом; исход дня (TP / SL / BE−)
  написан во всю клетку — размыто и со свечением в своём цвете, поверх
  него читаются число и процент. Дни без сделок приглушены.
- Показатели месяца одним блоком, hairline-сетка вместо карточек в карточках.
- Левая панель одинаковая во всех разделах: её цвета заданы явно и не зависят
  от палитры конкретного раздела, полоса прокрутки зарезервирована — при
  переходе между разделами меню не дёргается.
- Шрифт: Geist и Geist Mono. Все цифры моноширинные, ноль перечёркнут,
  чтобы колонки процентов не плясали по ширине.

## Что дальше

Перенос макета в само приложение (`static/`) — отдельная работа: разметка,
стили и рендер обзора там устроены иначе.
