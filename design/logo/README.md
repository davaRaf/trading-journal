# Фирменный знак

**Дельта с прорезанной S.** Треугольник работает сразу на три смысла: дельта — изменение
на языке трейдера, тело свечи с фитилями сверху и снизу, и буква S из названия,
прорезанная насквозь. Формы делят одну фигуру, ничего не приклеено сбоку.

## Готовые файлы

| Файл | Что |
|---|---|
| `mark.svg` | знак. Зелёный фиксированный, фитиль на `currentColor` — сам подстраивается под тему |
| `lockup.svg` | знак плюс название в строку |
| `favicon.svg` | тот же знак со светлым фитилём, для вкладки браузера |

Знак **вытянут по вертикали** из-за фитилей — пропорции `902 / 1315`. Размер задавать
по высоте, иначе в квадратной коробке он схлопнется в ниточку:

```css
.logo{ height:30px; width:auto; aspect-ratio:902/1315 }
```

## Где стоит

- экран входа — `design/auth/index.html`, над названием
- приложение — `static/index.html`, в сайдбаре, плюс фавиконка

## Как получен

Нарисован в Recraft V4.1 в режиме `vector` — она отдаёт настоящий SVG, а не картинку.
Обычные генераторы вроде nano banana для знака не годятся: растр нельзя перекрасить,
он мылится при масштабировании и разваливается в фавиконке.

Файл из генератора пришлось чистить, там всегда мусор:

- убран чёрный прямоугольник-подложка во весь холст — без этого знак нельзя положить
  ни на какой другой фон
- вырезана служебная подпись генератора
- `viewBox` обрезан по реальным границам фигуры
- фитиль переведён на `currentColor`, зелёный — на переменную темы

Оригиналы из генератора лежат в `gen/`.

## Черновики

| Файл | Что |
|---|---|
| `index.html` | восемь первых концепций знака |
| `delta.html` | шесть способов соединить дельту, S и свечу |
| `final.html` | выбранный знак: две версии, локапы, иконка приложения, проверки |

Проверки, которые знак обязан проходить: **лесенка размеров** до 16 пикселей,
**локап** со словом, **на светлом фоне**, **в один цвет**. Что не проходит эти четыре —
не логотип, а картинка.

Для мелких размеров есть версия без фитилей (`final.html`, «компактный»): тонкая линия
на 16 пикселях исчезает и оставляет мусорную точку.
