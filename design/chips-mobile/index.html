Корзина «убрать» на телефоне — тише

Красный бейдж на телефоне оказался слишком ярким: двадцать красных кружков перебивают сами подсказки. На компьютере он появляется только при наведении — там всё в порядке, меняем только телефон. Пять вариантов ниже — каждый на ширину телефона, живой: тапай по корзине, чтобы убрать, по плашке — чтобы выбрать.
