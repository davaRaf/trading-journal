# Экран входа

Прототип первого экрана: сюда человек попадает до журнала. Отсюда — вход или регистрация,
дальше основное приложение.

Открыть: `index.html` двойным кликом или через любой локальный сервер.
Приложение из корня репозитория он не трогает и не запускает.

## Что внутри

| Файл | Что |
|---|---|
| `index.html` | весь экран: разметка, стили, анимация фона, три языка |
| `fonts.html` | пробник шрифтов для цитаты — двенадцать вариантов рядом |

## Как устроено

**Фон рисуется кодом**, не картинкой: свечи растут из цены открытия, как на настоящем
графике, и медленно уходят влево. Весит килобайты, чёткий на любом экране, цвета берёт
из палитры. Картинку сюда ставить не надо — она не подстроится под тему и будет мылиться.

**Оформление зафиксировано** одной строкой в начале скрипта:

```js
const SETUP = { bg: 0, palette: "night", card: "accent", candleSize: 1, motion: true,
                candleEvery: 2.2 };
```

- `bg` — 0 свечи · 1 эквити · 2 стакан · 3 лента
- `palette` — night · dusk · haze · morning
- `card` — glass · split · bare · frame · accent
- `candleSize` — 0 обычные · 1 крупные · 2 очень крупные
- `candleEvery` — секунд на одну новую свечу, чем меньше тем быстрее

Остальные варианты не удалены — переключаются сменой значения.

## Языки

По умолчанию украинский, переключатель УКР · РУС · ENG в правом верхнем углу,
выбор запоминается в браузере. Словарь — объект `I18N` в скрипте, переведено всё
включая цитату с подсветкой и оценку надёжности пароля.

## Вход

Три сервиса: **Google · Discord · Telegram**. Плюс почтой.

Вход — одно поле «почта или никнейм», человек вводит что помнит.
Регистрация — никнейм, почта, пароль с индикатором надёжности.

**Кнопки сервисов пока ничего не делают** — это прототип. Чтобы они заработали, нужен
сервер, регистрация приложения у каждого сервиса и место, где хранить аккаунты.
Telegram вдобавок требует настоящий домен и на localhost не заводится в принципе.

## Что заложить при переходе на сервер

Правила для никнейма лучше решить до того, как появятся живые пользователи:

- уникальность, проверка во время ввода
- латиница, цифры и `_`; кириллицу не пускать — ломаются ссылки вида `/@давыд`
- забронировать `admin`, `support`, `api` и подобные
- решить, можно ли менять ник; если да — старый освобождать не сразу
