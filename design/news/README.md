# Новости

Экономический календарь: запланированные события на неделю с разбивкой по важности.

Открыть: `http://localhost:8173/design/news/` при запущенном `app.py`.
Просто открыть файл двойным кликом **не получится** — странице нужен наш сервер,
который ходит за календарём.

## Откуда данные

Недельный фид Forex Factory:

```
https://nfs.faireconomy.media/ff_calendar_thisweek.json
```

Официального API у Forex Factory нет, но этот фид отдаёт ровно то, что нужно:
`title`, `country`, `date` с часовым поясом, `impact`, `forecast`, `previous`.

## Три ограничения, из-за которых всё устроено именно так

**Только текущая неделя.** Проверено: `lastweek`, `nextweek`, `thismonth`, `today` —
все отдают 404. Ни истории, ни будущего дальше воскресенья.

**Жёсткий лимит запросов.** После восьми обращений за минуту фид отвечает
`Rate Limited`. Поэтому **из браузера пользователя его дёргать нельзя** — сто человек
откроют раздел, и заблокируют всех. Ходит только сервер, раз в полчаса.

**Условий использования у фида нет.** Для прототипа нормально, для продукта с подпиской —
серая зона. Платные источники с нормальными условиями: HorizonFX от $5/мес, Finnhub,
FXStreet, Trading Economics.

## Как устроено на сервере

В `app.py`:

- `GET /api/calendar` — отдаёт `{events, warning}`. Ходит в сеть не чаще раза в 30 минут
- каждая удачная выгрузка дописывается в `data/calendar/ГОД-Wнеделя.json` без дублей
- если сеть отвалилась — отдаётся последнее сохранённое с пометкой в `warning`

**Архив важнее, чем кажется.** Фид истории не отдаёт, взять её больше негде.
Каждый день без запуска сервера потерян навсегда. Через полгода у нас будет
полгода истории — и только тогда можно будет привязать старые сделки к новостям.

## Что на экране

- **дни недели** плюс кнопка «увесь тиждень»; под каждым днём точки по важности
- **важность**: Усі · Червоні · Помаранчеві · Жовті со счётчиками
- **валюта**: все валюты недели, счётчик за выбранный период, пустые приглушены
- карточка события залита цветом своей важности
- ближайшее ещё не наступившее помечено плашкой «скоро»
- время пересчитывается в пояс пользователя браузером

В режиме «увесь тиждень» события сгруппированы по дням с заголовками — так можно
выбрать «Червоні» и увидеть все важные новости недели сразу.

## Что дальше

Сам по себе календарь — товар, он есть у всех. Ценность появится в связке с журналом:

- у каждой сделки видно, какая новость была рядом по времени
- в Инсайтах строка вида «сделки в течение 30 минут после красной новости: 18 штук, −7%»
- предупреждение перед сессией: сегодня в 15:30 CPI

Для этого и нужен архив.
